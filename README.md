# PATH: Game

A souls-like boss rush game developed in Unity as my senior capstone project.

The game follows Shallo, a warrior seeking revenge against Susanoo after the disappearance of Kamehime. Players fight through challenging encounters featuring melee combat, enemy AI behaviors, and cinematic storytelling.

## My Role
**Lead Game Developer / Lead Programmer**

Responsible for designing and implementing core gameplay systems, including:
- Enemy AI behavior systems
- Combat mechanics
- Player interactions
- Cutscene systems
- Gameplay progression

## Features
- Custom enemy AI state machines with 10+ behavioral states
- Melee combat system with parry and counter mechanics
- Boss encounters with unique attack patterns
- Cinematic cutscene system
- World progression and map navigation
- Respawn/checkpoint system
